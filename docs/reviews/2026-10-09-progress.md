# Progress: the 1.35.0 release (eleven maintainer requests)

Branch `release/1.35.0` (from `main` at 1.34.0). One release: agents do not bump the version; the
lead adds one 1.35.0 bump and CHANGELOG section at the end, then asks the maintainer before any
push or tag.

## How the work runs

- **Agents:** headless Claude Code sessions on Haiku (`claude -p --model haiku --effort medium
  --permission-mode acceptEdits` plus a Bash allowlist, with push, tag, stash, `--no-verify` and
  `npm install` denied; see `.agent-reports/r135/run.sh`), each started inside its own worktree under `apiary/.worktrees/` (gitignored)
  so the repo's `.claude/settings.json` hooks run (lint after each edit; no stop with red
  typecheck, lint or architecture tests).
  - Haiku is chosen deliberately: it is where instructions get skipped, which shows which rules
    need a mechanical check.
  - The briefs and logs are in `.agent-reports/r135/`.
- **Review:** the lead reviews each package against the request and runs the `correct` skill for
  every class of shortcut found. The guard goes in its own commit, with proof that it fires.
- **Resume after a usage limit:** background-sleeper wakes every 30 min (CronCreate never fired in
  this environment). A stopped agent is resumed with
  `claude -p --resume <session_id> "continue"`, using the session id from the first line of its
  stream-json log.
