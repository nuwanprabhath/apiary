1. `cd /Users/nuwan/projects/pet-projects/apiary && git checkout chore/review-2026-09-26`.
2. Read the table below. `done` rows are finished and merged into the branch: do not redo them.
   `running` rows had an agent working in a worktree when the session stopped: check
   `git worktree list` and `.agent-reports/review/<WP>.md`; merge the worktree branch if its
   report says DONE, otherwise restart that package.
3. Start the next `todo` package whose dependencies are `done`.
4. Rules that bind every package: no AI attribution in commits; do not push, tag or release;
   subagents do not touch `package.json` `version` or `CHANGELOG.md` (the lead adds one
   1.26.0 section from the reports); never bare `git stash`; always use the npm scripts
   (native-module ABI trap).
5. When every row is `done` or `rejected`: run the full verification (typecheck, lint, `npm test`,
   `npm run test:component`, `npm run test:e2e`, `npm audit`), write the reply section at the end of
   the review, bump to 1.26.0 with one changelog section, and ask the maintainer before pushing.
