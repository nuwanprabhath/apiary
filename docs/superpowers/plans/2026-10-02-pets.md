# Pets Implementation Plan (1.31.0)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> This file is also the resume checklist: a resumed session reads the boxes and carries on from the
> first unchecked one. Branch: `feat/1.31.0`. Spec: `docs/superpowers/specs/2026-10-02-pets-design.md`.

**Goal:** Data-only, Haiku-designed pets that live in the collapsed rail + status bar, wander on
their own (brain in a Web Worker), react to Claude, and can be chatted with — plus the grip fix.

**Architecture:** `shared/pets/` (spec, validator, prompts, built-in, pure habitat + brain) →
`main/pets/` (store in `pets.json`, service running `claude -p` through a shared one-shot runner
extracted from `ThemeGenerator`) → IPC → `renderer/features/pets/` (SVG sprite from a parts library,
one fixed overlay layer, CSS-transition movement, worker brain, bubbles, chat, settings section).

**Tech Stack:** Electron, React 19, strict TS, Vitest (unit/integration/component browser mode),
Playwright e2e.

## Global Constraints

- A pet is data, never code; `validatePet` is the only way in; no markup from a pet reaches the DOM
  except as text nodes.
- Pet state lives in `userData/pets.json` (like `themes.json`, not `settings.json` — see
  main/CLAUDE.md "Changing a default reaches nobody"). `enabled` defaults to false.
- Size 20–48 px, default 28. Up to 3 active pets.
- Default model `haiku`; choices `haiku | sonnet | opus` (`THEME_MODELS`).
- Voice: at most one call per pet per hour, only while a window is visible and pets are enabled;
  context = counts + session titles, never transcript content. Never log pet chat text or lines.
- No rAF loops or JS-driven per-frame positions on the main thread; animate only transform/opacity.
- No `backdrop-filter`; no literal colours or radii > 3px in `styles.css` except inside the pet SVG
  (which takes its colours from the validated spec as SVG attributes).
- Every change: `npm run typecheck && npm run lint`, tests in the cheapest layer, one 1.31.0
  CHANGELOG section, commit subject `feat(pets): 1.31.0 — …` (≤150 chars), no AI attribution.
- Never push/tag without asking.

rendered as a text node — test only that it is length-capped and stripped of control chars);
prototype keys (`__proto__`) ignored; validating twice is identity.

### Task 9: Brain (pure) + worker

**Files:** Create `src/shared/pets/brain.ts`, `src/renderer/features/pets/petBrain.worker.ts`,
`src/renderer/features/pets/brainClient.ts`; test `tests/unit/petBrain.test.ts`.

```ts
export type Activity = 'idle'|'wander'|'run'|'sit'|'read'|'sleep'|'stretch'|'wave'|'dance'|'visit'|'watch'|'celebrate'|'nervous'|'held'
export type Face = 'happy'|'blink'|'sleepy'|'surprised'|'focused'|'love'|'worried'
export interface BrainPet { id: string; traits: PetSpec['traits']; lines: PetSpec['lines']; place: PetPlace; size: number }
export type BrainEvent =
  | { kind: 'pets'; pets: BrainPet[] } | { kind: 'habitat'; railLength: number; barLength: number; hasRail: boolean }
  | { kind: 'held'; id: string } | { kind: 'dropped'; id: string; place: PetPlace }
  | { kind: 'claude'; working: number; waiting: number; finishedNow: boolean }
  | { kind: 'sleep'; id: string; on: boolean } | { kind: 'reducedMotion'; on: boolean } | { kind: 'hour'; hour: number }
export interface Command { id: string; activity: Activity; face: Face; to?: PetPlace; ms: number; say?: { text: string; kind: 'speech'|'thought' } }
export class Brain { constructor(seed: number); handle(e: BrainEvent): Command[]; tick(dtMs: number): Command[] }
```

Needs: energy falls while active, rises asleep; boredom rises idle; social rises alone. Choice =
weighted by needs × traits (+ night sleepiness). Speech at most every 120 s per pet (finished /
waiting events may speak sooner, once). Commands only on changes (not every tick). Reduced motion
→ no `to`. Worker: `onmessage` → `brain.handle`, `setInterval(250)` → `tick`; `pause`/`resume`
messages; posts `Command[]` batches.

- [x] Tests (seeded): tired pet sleeps within N simulated minutes; `claude working` → `watch` for
      every awake pet; `finishedNow` → `celebrate`; sociable pair → a `visit` targets the other's
      place; every `to` within 0..1 and region valid (rail only when hasRail); reduced motion has
      no `to`; speech rate ≤ 1/120 s. Implement; commit.
